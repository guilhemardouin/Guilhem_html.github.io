Introduction à Linux

Initié par Linus Torvalds en 1991, Linux désigne un noyau de système d'exploitation de type UNIX, open-source et gratuit, massivement utilisé pour propulser les infrastructures serveurs et cloud mondiales.

Caractéristiques Fondamentales

  • Sécurité et Stabilité : Architecture robuste limitant la propagation de failles majeures.
  • Distributions (Distros) : Versions prêtes à l'emploi adaptées aux besoins (ex: Ubuntu, Debian, Rocky Linux).
  • Multi-utilisateurs et Multi-tâches : Conçu dès l'origine pour la gestion de serveurs réseau d'envergure.

Structure type des répertoires

/        -> Racine du système global
/etc/    -> Fichiers de configurations des applications et services
/var/log/-> Emplacement des fichiers de rapports (logs) système
/home/   -> Répertoires personnels des différents utilisateurs
