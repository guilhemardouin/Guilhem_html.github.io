Introduction à GitHub

GitHub est une plateforme web d'hébergement de code source qui s'appuie sur le système de versionnage Git. C'est l'un des outils de collaboration les plus populaires au monde pour les développeurs.

Fonctionnalités Collaboratives

  • Dépôts distants (Remote Repositories) : Permet de sauvegarder et de synchroniser son code dans le cloud.
  • Pull Requests : Outil central pour proposer des modifications de code et les soumettre à la révision de l'équipe avant intégration.
  • Issue Tracking : Gestion des tâches, des demandes d'améliorations et des corrections de bugs.

Commandes pour synchroniser avec GitHub

# Lier votre dépôt Git local à un dépôt distant sur GitHub
git remote add origin https://github.com

# Envoyer vos validations locales vers la branche principale sur GitHub
git push -u origin main
