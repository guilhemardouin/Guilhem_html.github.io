Introduction à la ligne de commande Linux

La ligne de commande Linux, ou CLI (Command Line Interface), trouve ses racines dans le système d'exploitation Unix développé à la fin des années 1960. Lorsque Linus Torvalds a créé le noyau Linux en 1991, il s'est appuyé sur les outils du projet GNU pour fournir un environnement textuel complet et ultra-performant aux développeurs et administrateurs système.

Interagir avec un système via le terminal permet d'automatiser des tâches, de gérer des serveurs à distance et de manipuler des fichiers avec une rapidité et une précision impossibles à atteindre avec une interface graphique standard. C'est une compétence fondamentale pour tout technicien ou ingénieur en informatique.

Le terminal exécute un interpréteur de commandes (le plus souvent Bash). L'utilisateur saisit le nom d'un programme, suivi éventuellement d'options (ou arguments) pour modifier son comportement de base.

Les commandes Linux fondamentales

Les commandes permettent d'interagir directement avec le système de fichiers. Voici quelques-unes des commandes de navigation et de gestion les plus courantes :

  • pwd : affiche le chemin complet du répertoire courant (Print Working Directory)
  • ls : liste le contenu d'un répertoire
  • cd : change de répertoire pour naviguer dans l'arborescence
  • mkdir : crée un nouveau répertoire
  • rm : supprime des fichiers ou des répertoires

Options et Arguments courants

Les options modifient la façon dont une commande s'exécute. Elles sont généralement précédées d'un tiret (-). Voici quelques exemples incontournables :

  • -l : option de "ls" pour afficher la liste au format détaillé (permissions, tailles, dates)
  • -a : option de "ls" pour afficher tous les fichiers, y compris les fichiers cachés
  • -r : option de "rm" pour supprimer un répertoire et son contenu de manière récursive
  • .. : argument utilisé avec "cd" pour remonter d'un niveau dans le répertoire parent

Exemple de session dans le Terminal

            
                $ pwd
                /home/sio/documents

                $ mkdir cours_linux
                $ cd cours_linux

                $ touch exercice.txt
                $ ls -la
                total 8
                drwxr-xr-x 2 sio sio 4096 Sep 29 09:17 .
                drwxr-xr-x 3 sio sio 4096 Sep 29 09:15 ..
                -rw-r--r-- 1 sio sio    0 Sep 29 09:17 exercice.txt
