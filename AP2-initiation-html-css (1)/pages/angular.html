Introduction à Angular

Développé par Google, Angular est un framework open-source basé sur TypeScript, spécialisé dans la création d'applications web de type SPA (Single Page Application).

Architecture et Composants

  • Composants (Components) : Les briques de l'interface qui associent une vue HTML, des règles CSS et une logique métier.
  • TypeScript : Offre un typage strict et des fonctionnalités de programmation orientée objet avancées.
  • Data Binding : Synchronisation automatique des données entre le code logique et le rendu visuel.

Exemple de composant Angular (TypeScript)

import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  template: '<h1>{{ titre }}</h1>',
  styleUrls: ['./app.component.css']
})
export class AppComponent {
  titre = 'Bienvenue sur notre application Angular SIO !';
}
