Introduction à Python

Créé par Guido van Rossum en 1991, Python est un langage de programmation interprété de haut niveau, reconnu pour sa syntaxe claire, épurée et hautement lisible.

Domaines d'application

  • Scripting et automatisation : Idéal pour automatiser des tâches systèmes complexes en SIO.
  • Data Science et IA : Le langage roi du Machine Learning et de la manipulation de données (Pandas, NumPy).
  • Développement Web : Via des frameworks robustes tels que Django ou Flask.

Exemple de code Python

# Définition d'une fonction de calcul
def verifier_admission(note):
    if note >= 10:
        return "Admis en année supérieure"
    else:
        return "Rattrapages nécessaires"

# Appel de la fonction
resultat = verifier_admission(14)
print(f"Statut de l'étudiant : {resultat}")
