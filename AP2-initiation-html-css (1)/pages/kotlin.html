Introduction à Kotlin

Développé par JetBrains et lancé en 2011, Kotlin est un langage de programmation moderne, statiquement typé, conçu pour être entièrement interchangeable avec Java. Il est officiellement soutenu par Google pour le développement Android depuis 2017.

Pourquoi utiliser Kotlin ?

  • Concis : Réduit drastiquement la quantité de code passe-partout (boilerplate) par rapport à Java.
  • Sécurité d'usage (Null Safety) : Intègre nativement la protection contre les fameuses erreurs d'exception de pointeur nul (NullPointerException).
  • Multiplateforme : Utilisable pour Android, les applications serveurs ou le développement natif.

Exemple de code Kotlin

fun main() {
    // Variable immuable avec déduction de type
    val message = "Bonjour le SIO"
    println(message)
    
    // Fonction avec gestion de la sécurité des variables nulles
    var nom: String? = null
    println(nom?.length ?: "Le nom est vide")
}
