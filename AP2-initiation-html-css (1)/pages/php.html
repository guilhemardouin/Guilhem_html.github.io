Introduction à PHP

Créé par Rasmus Lerdorf en 1994, PHP (Hypertext Preprocessor) est un langage de script open-source spécialement conçu pour le développement d'applications web s'exécutant côté serveur.

Lorsqu'un utilisateur demande une page PHP, le serveur exécute le code PHP, génère du HTML dynamique, puis renvoie uniquement le résultat HTML au navigateur de l'utilisateur.

Fonctionnalités Majeures

  • Dynamisme : Génère des pages personnalisées à la volée.
  • Bases de données : S'intègre nativement et efficacement avec les systèmes comme MySQL ou PostgreSQL.
  • Traitement de formulaires : Récupère les données envoyées en méthode POST ou GET pour les sécuriser et les traiter.

Exemple de code PHP

<?php
// Exemple de traitement de variable et d'affichage dynamique
$nomUtilisateur = "Étudiant SIO";
echo "<h2>Bienvenue, " . htmlspecialchars($nomUtilisateur) . " !</h2>";

// Structure conditionnelle simple
if (date("H") < 18) {
    echo "<p>Passez une excellente journée d'apprentissage.</p>";
} else {
    echo "<p>Bonsoir !</p>";
}
?>
