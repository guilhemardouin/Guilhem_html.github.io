Introduction à Git

Créé par Linus Torvalds en 2005, Git est un système de gestion de versions décentralisé. Il permet de suivre l'évolution des fichiers sources d'un projet informatique au fil du temps.

Flux de travail Git de base

  • Working Directory : L'espace local où vous modifiez directement vos fichiers.
  • Staging Area (Index) : La zone de préparation où vous listez les changements à inclure dans le prochain instantané.
  • Repository local : Là où l'historique complet est enregistré de façon permanente après validation.

Commandes Git indispensables

# Initialiser un nouveau dépôt local
git init

# Ajouter les fichiers modifiés à la zone de préparation
git add .

# Enregistrer les modifications avec un message explicite
git commit -m "Ajout des nouvelles structures de fichiers pour les pages de cours"
