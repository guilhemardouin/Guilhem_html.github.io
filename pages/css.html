Introduction à CSS

Le CSS (Cascading Style Sheets) a été proposé initialement par Håkon Wium Lie en 1994, alors qu'il travaillait au CERN aux côtés de Tim Berners-Lee. Il a été développé pour pallier les limites d'HTML, qui gérait alors à la fois le fond et la forme des pages web.

L'objectif principal du CSS est de séparer la structure d'un document (gérée par HTML) de sa présentation visuelle. Cette séparation facilite le maintien des sites, permet de modifier l'apparence de tout un site en modifiant un seul fichier, et adapte l'affichage sur une multitude d'écrans différents.

CSS (Feuilles de style en cascade) est le langage utilisé pour styliser les pages web. Il fonctionne en appliquant des règles de style sur les éléments HTML à l'aide de sélecteurs, de propriétés et de valeurs.

Les sélecteurs CSS

Les sélecteurs CSS permettent de cibler les éléments HTML auxquels vous souhaitez appliquer des styles. Voici quelques-uns des types les plus courants :

  • Sélecteur de balise : cible tous les éléments d'un type (ex: p, h1)
  • Sélecteur de classe (.) : cible les éléments dotés d'un attribut class spécifique (ex: .menu)
  • Sélecteur d'identifiant (#) : cible un élément unique doté d'un attribut id spécifique (ex: #burger)
  • Sélecteur universel (*) : cible la totalité des éléments de la page

Propriétés CSS courantes

Les propriétés CSS définissent l'aspect visuel que prendront les éléments ciblés. En voici quelques exemples fondamentaux :

  • color : modifie la couleur du texte
  • background-color : définit la couleur d'arrière-plan d'un élément
  • font-size : change la taille de la police de caractères
  • margin et padding : gèrent les espaces extérieurs et intérieurs (modèle de boîte)
  • display : modifie le comportement d'affichage (ex: block, inline, flex, grid)

Exemple de code CSS

            
                /* Cibler le titre principal */
                h1 {
                    color: #2c3e50;
                    font-size: 2.5rem;
                    text-align: center;
                }

                /* Cibler les paragraphes d'exemple */
                p {
                    line-height: 1.6;
                    color: #333333;
                }

                /* Cibler un élément par sa classe */
                .logo {
                    font-weight: bold;
                    text-transform: uppercase;
                }
