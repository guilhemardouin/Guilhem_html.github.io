Introduction à JavaScript

Créé en 1995 par Brendan Eich pour le navigateur Netscape, JavaScript (JS) est un langage de script léger, orienté objet et principalement connu comme le langage de programmation des pages web.

Contrairement au HTML et au CSS qui gèrent la structure et l'apparence, JavaScript apporte l'interactivité, le dynamisme et le comportement logique directement sur le navigateur de l'utilisateur (côté client).

Concepts Clés

  • Variables : Stockage de données avec let, const ou var.
  • DOM (Document Object Model) : API permettant à JS de modifier dynamiquement la structure HTML et le CSS.
  • Événements : Interceptions des actions de l'utilisateur (clics, touches, soumissions de formulaires).

Exemple de code JavaScript

// Sélectionner l'élément burger et ajouter un gestionnaire d'événement
const burger = document.getElementById('burger');
const menu = document.getElementById('menu');

burger.addEventListener('click', () => {
    menu.classList.toggle('active');
    const expanded = burger.getAttribute('aria-expanded') === 'true';
    burger.setAttribute('aria-expanded', !expanded);
});
